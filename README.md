# Sonora Studio — Simple Static Website

Tidak membutuhkan Termux, Node.js, atau server lokal.

## Cara pakai
1. Ekstrak ZIP.
2. Buka folder `sonora_studio_simple`.
3. Buka `index.html` menggunakan Chrome atau HTML Preview.

## Menu
- Generate Musik
- Upload & Cover Audio
- Upload & Extend Cover
- Kling 2.6 Motion Control (placeholder untuk update berikutnya)

## Catatan penting
Ini masih frontend statis. Tombol menyiapkan dan menampilkan JSON; belum mengirim permintaan ke layanan API dan belum menghasilkan audio. Fitur extend harus dicocokkan dengan endpoint API extend yang benar. Untuk integrasi sungguhan, gunakan backend/serverless dan simpan API key sebagai secret, jangan di JavaScript publik.
